<idea>
**Design Movement:** Cartografía forense neo-brutalista chilena.

**Core Principles:** La interfaz debe sentirse como una mesa de análisis de inteligencia con capas topográficas, no como un panel SaaS genérico; la información debe priorizar trazabilidad, fuente y confianza antes que ornamentación; las relaciones deben emerger como rutas sobre un territorio investigativo; cada componente debe distinguir con claridad entre hecho confirmado, evidencia manual, hipótesis de IA y tarea pendiente.

**Color Philosophy:** La paleta usa fondo grafito profundo, verde cobre oxidado y acentos ámbar de expediente. El grafito comunica investigación nocturna y concentración; el verde cobre remite a materialidad chilena y señales técnicas; el ámbar funciona como marca de evidencia y advertencia. Se evita el púrpura genérico y se privilegia una atmósfera sobria, casi cartográfica.

**Layout Paradigm:** Estructura de tablero asimétrico con una columna izquierda de semillas y transforms, un lienzo de grafo dominante desplazado hacia la derecha, y una bitácora inferior tipo expediente. El layout no debe quedar centrado; debe parecer una estación de trabajo donde la vista de grafo ocupa el territorio principal.

**Signature Elements:** Líneas de coordenadas sutiles en el fondo; tarjetas con bordes rectos y esquinas apenas suavizadas, como fichas de caso; badges de riesgo y fuente inspirados en sellos de expediente.

**Interaction Philosophy:** Las acciones deben sentirse como expansión investigativa: al ejecutar un transform, el usuario ve una nueva relación, su evidencia y su estado de confianza. Los conectores human-in-the-loop se muestran como compuertas manuales, no como errores.

**Animation:** Transiciones discretas de 180–260 ms; aparición de nodos con expansión radial tenue; líneas del grafo con pulso muy bajo cuando representan inferencias; estados hover con desplazamiento mínimo y sombra direccional. Nunca usar animaciones decorativas que diluyan el tono forense.

**Typography System:** Títulos con IBM Plex Sans Condensed para densidad técnica; cuerpo con Source Sans 3 para legibilidad; números, identificadores y RUTs con IBM Plex Mono. La jerarquía visual debe favorecer etiquetas compactas, datos tabulares y encabezados contundentes.
</idea>

**Design Movement:** Minimalismo institucional de archivo público.

**Core Principles:** La herramienta debe parecer un sistema cívico de consulta documental; cada dato debe estar acompañado de fuente y fecha; la jerarquía debe ser clara y austera; el grafo debe presentarse como una extensión del expediente, no como una visualización espectacular.

**Color Philosophy:** Blanco hueso, azul tinta, gris papel y acento rojo notarial. La intención emocional es confianza institucional, claridad y neutralidad. El rojo se reserva para riesgos, errores y datos no verificados.

**Layout Paradigm:** Layout tipo expediente digital con navegación lateral estrecha, panel central documental y grafo como módulo embebido. Se usa mucho espacio negativo para enfatizar trazabilidad y reducir ruido cognitivo.

**Signature Elements:** Sellos de estado documental; separadores de línea fina; cajas de evidencia con numeración y citas internas.

**Interaction Philosophy:** El usuario avanza por pasos formales: crear caso, agregar semilla, ejecutar transform, revisar evidencia, aprobar inferencias. Las interacciones priorizan confirmación y auditabilidad.

**Animation:** Movimiento casi imperceptible, fades de 120–180 ms, foco accesible muy visible y estados de carga con barras lineales sobrias.

**Typography System:** Libre Franklin para títulos y Noto Sans para cuerpo, con JetBrains Mono para identificadores. La tipografía debe sentirse gubernamental, robusta y sobria.
</idea>

**Design Movement:** Cyber-Andes analítico.

**Core Principles:** La interfaz combina topografía andina abstracta con análisis de redes; cada módulo debe sentirse orientado a descubrimiento; la IA debe presentarse como copiloto analítico, no como caja negra; las hipótesis deben separarse visualmente de hechos.

**Color Philosophy:** Azul noche, cian glacial, arena del desierto y magenta mínimo para alertas críticas. El azul noche concentra la investigación, el cian marca relaciones digitales, la arena conecta con territorio chileno y el magenta solo aparece como señal de riesgo.

**Layout Paradigm:** Lienzo diagonal con paneles flotantes; el grafo se superpone a una retícula topográfica; la navegación funciona como capas de mapa que se activan y desactivan.

**Signature Elements:** Curvas de nivel abstractas; nodos como estaciones de observación; chips de IA con forma de anotaciones laterales.

**Interaction Philosophy:** El usuario explora capas y activa transformaciones como si encendiera sensores. Los resultados aparecen como trayectorias, no como simples listas.

**Animation:** Trazos de líneas con efecto de dibujo progresivo; parallax sutil en patrones topográficos; microinteracciones de chips con expansión horizontal.

**Typography System:** Space Grotesk para títulos, Manrope para cuerpo y Roboto Mono para datos técnicos. La jerarquía combina títulos amplios con etiquetas técnicas compactas.

## Enfoque seleccionado

Se selecciona **Cartografía forense neo-brutalista chilena**. Este enfoque refuerza mejor el objetivo de una herramienta de investigación tipo Maltego para Chile porque combina análisis de grafos, sensación de expediente técnico, énfasis en evidencia y una identidad local sobria sin caer en patrones SaaS genéricos.
